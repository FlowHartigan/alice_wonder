Pour chaque nouvel écart, copier une ligne avec : ID stable, carte/pièce concernée (`Cxx`/`Sxx`/`Jxx`), constat et preuve, attendu et source, état (`ouvert`/`expliqué`), prochaine action ou justification de clôture. Inclure notamment les pièces absentes, supplémentaires, illisibles ou non attribuées ; séparer les divergences de source des écarts entre exemplaires.

## PV à remplir sur le lot

Le deuxième lecteur reprend la version datée du relevé et les preuves originales, recompte sans se fier au total du premier lecteur, puis rapproche les tables carte → pièce et pièce → carte. Conserver les écarts et les relire après toute correction. Dans « Constat », noter le nombre observé, le nombre non vérifié et les IDs ou preuves associés ; dans « Résultat », noter `conforme`, `écart` ou `non vérifiable`, pas `conforme` sur une case simplement préimprimée.
